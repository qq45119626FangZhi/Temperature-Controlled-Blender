## 1. 产品与硬件要点

- 智能温控搅拌机，MCU = STM32F103RCT6，FreeRTOS + HAL + Keil MDK-ARM。
- 人机界面：0.96" SSD1315 OLED + **4 个物理按键**（PC6/PC7/PC8/PC9，内部上拉、按下为低）。
- 三通道并存：RS485/Modbus RTU、CAN（本期未做）、**蓝牙 BLE 透传**。
- 蓝牙芯片 **ECB01CV2-SOP8**（早期文档写的 ECB01C-TSSOP16 已更正），接 **USART2：PA2(TX→BL-RXD) / PA3(RX←BL-TXD)**，实测波特率 **9600 8N1**（上电 AT 自动识别，非手册默认的 115200）。
  - 早期文档曾把 RS485 与蓝牙串口写反，已按原理图更正：**RS485 在 UART4 (PC10/PC11)**。
- 蓝牙模块**不支持改自定义名**，出厂名 `BT_ECB1A6B01BA2`，MAC `ECB1A6B01BA2`；不要用系统蓝牙"配对"。

## 2. BLE GATT 链路（App 必须遵守）

| 项         | 值                                                                    |
| --------- | -------------------------------------------------------------------- |
| 类型        | BLE（GATT），**不是**经典蓝牙 SPP                                             |
| Service   | `FFF0` → `0000fff0-0000-1000-8000-00805f9b34fb`                      |
| Notify 特征 | `FFF1` → `0000fff1-...-00805f9b34fb`，**必须先写 CCCD 订阅**，否则收不到任何应答      |
| Write 特征  | `FFF2` → `0000fff2-...-00805f9b34fb`，写入类型 **Write Without Response** |
| 单包        | 默认 MTU=23 时净荷 ≤20 字节；手机请求 MTU=247 后可达 244 字节                         |
| 发送间隔      | **两次发送 ≥100 ms**（本 App 统一取 120 ms）                                   |
| 空闲断开      | 手机 3 分钟无数据模块主动断开 → App 每 1 s 轮询作心跳                                   |
| 连接上报      | 模块向 MCU 输出 `CONNECT OK\r\n` / `DISCONNECT\r\n`，映射到状态字 0x0005 bit8    |

## 3. 业务协议：蓝牙直接透传 Modbus RTU 帧（D3 = A 案）

- 手机端当 **Modbus 主站**；帧格式、寄存器表与 RS485 完全一致。
- 从机地址 **1**；功能码 **03 / 06 / 10**；线圈类 01/02/05/0F **不支持**。
- CRC16/MODBUS（初值 0xFFFF、多项式 0xA001、**低字节在前**）；寄存器 16bit **大端**。
- 异常码：`02` 非法地址/只读、`04` 数值越界或保护联锁拒绝、`06` 面板按键占用。
- 未提 MTU 时一次最多读 **7 个寄存器**（应答 5+2×7 = 19 B）；提 MTU 后可整表读。
- **仲裁**：面板有按键动作后 **8 秒**内，所有通信写入返回 `06`；App 需提示用户稍候重试。
- 面板 8s 内写命令会被拒绝；故障态下"启动"命令被拒绝（`04`）。

### 文档中的帧样例（已用 CRC 程序逐条复算，全部一致）

| 功能              | HEX                       |
| --------------- | ------------------------- |
| 读 0x0000~0x0006 | `01 03 00 00 00 07 04 08` |
| 读 0x0007~0x000D | `01 03 00 07 00 07 B5 C9` |
| 读 0x000E~0x000F | `01 03 00 0E 00 02 A5 C8` |
| 写目标转速 300 rpm   | `01 06 00 03 01 2C 79 87` |
| 启动（bit0）        | `01 06 00 07 00 01 F9 CB` |
| 停止（bit1）        | `01 06 00 07 00 02 B9 CA` |

## 4. 保持寄存器表（32 个，0x0000~0x001F）

| 地址              | 名称               | 单位                      | 属性      |
| --------------- | ---------------- | ----------------------- | ------- |
| 0x0000          | 当前液温             | int16 / 0.1℃            | R       |
| 0x0001          | **目标液温**         | int16 / 0.1℃（0~1000）    | **R/W** |
| 0x0002          | 当前转速             | int16 / RPM             | R       |
| 0x0003          | **目标转速**         | int16 / RPM（0~500）      | **R/W** |
| 0x0004          | 剩余时间             | uint16 / s              | R       |
| 0x0005          | 系统状态字            | 位域                      | R       |
| 0x0006          | 故障码              | 位域                      | R       |
| 0x0007          | **控制命令字**        | 位域（写后自动清零）              | **R/W** |
| 0x0008          | 铝板温度             | int16 / 0.1℃            | R       |
| 0x0009          | 加热占空比            | %                       | R       |
| 0x000A          | 电机占空比            | %                       | R       |
| 0x000B          | **设定时间**         | uint16 / s（0~999，0=不限时） | **R/W** |
| 0x000C          | 风扇状态             | 0/1                     | R       |
| 0x000D / 0x000E | 设备 ID 低 / 高 16 位 |                         | R       |
| 0x000F          | 固件版本             | 高字节主 / 低字节次             | R       |
| 0x0010 / 0x0011 | 从机地址 / 波特率代码     | 重启生效                    | R/W     |
| 0x0012 / 0x0013 | 累计运行时间 低 / 高     | s                       | R       |
| 0x0018~0x001D   | PID 增益镜像         |                         | 只读预留    |

状态字 `0x0005` bit：0 电机运行、1 加热中、2 风扇、3 故障、4 计时中、5 RTC 有效、6 面板刚操作、**8 蓝牙在线**。  
命令字 `0x0007` bit：0 启动、1 停止、2 清故障、3 立即保存参数、4 恢复默认。

## 5. 物理 4 按键定义（`menu_ui.h`）

| 键    | 引脚  | 短按                         | 长按                 |
| ---- | --- | -------------------------- | ------------------ |
| KEY1 | PC6 | 切换焦点：速度 → 铝板温度 → 液体温度 → 时间 | ≥600ms 进/出 RTC 校时页 |
| KEY2 | PC7 | 当前项参数 +                    | 600ms 后每 80ms 连发   |
| KEY3 | PC8 | 当前项参数 −                    | 600ms 后每 80ms 连发   |
| KEY4 | PC9 | 电机运行 / 停止                  | —                  |

参数步长/上限：转速 0~~500 rpm 步进 5；铝板限温 0~~120℃ 步进 1；液温 0~~100℃ 步进 1；定时 0~~999 s 步进 1（0=不限时）。

## 6. 关键设计结论：App 如何"对应物理 4 键"

《通信协议.md》13-B 明确写道：蓝牙写入走 `Menu_UiComm*` 桥，**等同于在面板上改设定**，  
但**它不是"远程按键"**，无法操作校时页 / 焦点切换。寄存器表里也不存在"按键注入"寄存器。

因此本 App 采用**语义等价**实现，不改下位机固件：

| App 软键    | 实现                                                           |
| --------- | ------------------------------------------------------------ |
| KEY1 切换焦点 | App 本地轮转焦点：转速(0x0003) → 液温(0x0001) → 定时(0x000B)。下位机面板焦点不随之变化 |
| KEY2 参数 + | 对当前焦点寄存器发 `06` 写单寄存器，步长与面板一致                                 |
| KEY3 参数 − | 同上，下限钳到 0                                                    |
| KEY4 启停   | 对 0x0007 写 bit0=启动 / bit1=停止，依据状态字 bit0 判断当前状态               |
| KEY1 长按   | 显示设备信息（ID/固件版本/MTU），并提示"RTC 校时页未通过蓝牙开放，请在面板校时"               |

**焦点不含"铝板温度"**：该设定在 Modbus 表中没有可写寄存器（0x0008 是只读实测值），  
`App_CommWriteReg()` 也没有对应 case，写入会返回 `02`。故只轮转 3 个可写参数。

## 8. 本 Android 工程的实现要点

- 纯 **Java**，无 AndroidX / 三方依赖；`minSdk 26 / targetSdk 33 / compileSdk 36.1`，AGP 9.3.0 + Gradle 9.5.0。
- `ModbusProtocol`：组帧、CRC16/MODBUS、应答帧长度推断（分片重组）、异常码文本。
- `DeviceState`：寄存器快照 + 温度/状态/故障解码。
- `BleManager`：扫描 → 连接 → `requestMtu(247)` → 发现 FFF0 → 订阅 FFF1 CCCD → FFF2 无响应写；  
  **单帧 outstanding 串行发送**（避免 Android BLE 栈并发限制与应答错配），120ms 间隔，  
  1s 轮询心跳，1.2s 应答超时，Notify 分片重组 + CRC 校验。
- `MainActivity`：状态卡、焦点大数字、2×2 四键、HEX 通信日志；KEY2/KEY3 支持长按连发  
  （面板 80ms 改为 250ms，以适配 BLE 发送间隔）。
