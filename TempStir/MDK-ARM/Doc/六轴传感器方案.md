# TempStir 六轴传感器（LSM6DSM）方案

> 状态：**方案待确认（未写代码）**　日期：2026-11-06　适用固件：v1.1 之后（计划 v1.2）
> 目标一句话：把 6 轴（3 轴加速度 + 3 轴陀螺）**全部能力**接进来，并用它实现**电机加减速转动的平滑/可测/可诊断**。

---

## 1. 现状确认（先把事实摆清）

| 项 | 现状 |
|---|---|
| 硬件接口 | SPI2：PB13=SCK / PB14=MISO / PB15=MOSI / PB12=CS（软件片选），INT1=PC4 / INT2=PC5 —— 已在 `int_bsp_pins.h` 登记 |
| 外设初始化 | `MX_SPI2_Init()`：主机、8 bit、MSB、PCLK/8（72MHz/8 = **9 MHz**）、NSS 软件 |
| BSP 层 | `int_spi.c`：`Int_SpiInit()` 仅释放 CS；`Int_SpiReadReg()/WriteReg()` 是通用单寄存器原语 |
| 器件驱动 | **没有**（无寄存器表、无初始化、无数据读取） |
| 业务使用 | **没有**（`Int_SpiReadReg` 全项目零调用，WHO_AM_I 从未读过） |
| 板上是否贴件 | **待确认**（需查 BOM/实物，读不到 `0x6A` 即视为未贴件） |

结论：现在是"SPI 线通了，器件没驱动"，本方案就是补这一整层。

## 2. 目标与范围

### 2.1 本期要覆盖的 6 轴能力（陀螺仪功能全覆盖）

| # | 能力 | 说明 | 优先级 |
|---|---|---|---|
| G1 | 器件识别与自检 | WHO_AM_I=0x6A、软复位（`CTRL3_C.SW_RESET`）、boot 完成、自检（`CTRL5_C.ST_XL/ST_G`） | P0 |
| G2 | 三轴加速度 | ±2/4/8/16 g 可选，换算 mg | P0 |
| G3 | 三轴角速度 | ±125/245/500/1000/2000 dps 可选，换算 mdps | P0 |
| G4 | 片上温度 | `OUT_TEMP_L/H`，用于零偏温漂补偿 | P0 |
| G5 | 采样与滤波 | ODR 12.5~6660 Hz、LPF1/LPF2、HPF（去重力/去零偏）、BDR | P0 |
| G6 | 数据就绪中断 | INT1 上 `INT1_DRDY_XL / INT1_DRDY_G`，避免轮询丢点 | P0 |
| G7 | FIFO 连续采样 | 512 B FIFO（约 28 组 6 轴样本），用于高 ODR 突发采集 | P1 |
| G8 | 零偏校准 | 静止均值法 + 温度补偿表（可选）；结果存 EEPROM | P0 |
| G9 | 姿态解算 | 加速度求 roll/pitch，角速度积分 + 互补滤波（或 Mahony）输出四元数/欧拉角；yaw 漂移说明 | P1 |
| G10 | 运动状态判据 | 静止 / 转动 / 振动 / 倾斜 / 跌落 / 冲击 | P0 |
| G11 | 自由落体 / 6D 方向 / 单击双击 / 唤醒 | 用器件内嵌功能，走 INT1/INT2，不占 CPU | P2 |
| G12 | 低功耗 | 停机时切 26 Hz + 低功耗模式（或断电），启动前唤醒 | P2 |
| G13 | FSM / MLC（可编程状态机） | 器件内嵌，可做"启动/停止事件"硬件判定 | P3（可选） |
| G14 | Sensor Hub | 外接磁力计等其他传感器（本板未用） | 不启用 |

### 2.2 电机加减速应用（本方案的落点）

现有速度环：`app_motor` 转速 PID（200 ms 周期）+ **软启动斜坡 5%/周期**（≈0.25 s 到 100%）。问题：斜坡是"占空比斜坡"，不是"转速斜坡"，实际角加速度随负载变化，搅拌液体会出现**启动飞溅、停止涌浪**。

| # | 功能 | 做法 | 依赖 |
|---|---|---|---|
| M1 | **S 曲线加减速** | 由目标转速生成带加速度上限的斜坡（梯形速度曲线；进阶 S 形），按 200 ms 周期喂给 PID 设定值 | 软件即可，陀螺用于验证 |
| M2 | **实测角加速度** | 陀螺 ω 微分（带滤波）得 α（dps/s 或 rad/s²），寄存器可读 | G3/G5 |
| M3 | **加减速时间测量** | 检测 α 符号/幅值沿，测"起步→匀速""匀速→停转"的实际时间，作为验收指标 | M2 |
| M4 | **打滑/失步判定**（陀螺**与编码器交叉校验**） | 同轴安装时 `ω_imu` 应与编码器 `ω_enc` 一致；持续偏差 > 阈值 → 联轴器/皮带打滑、桨叶空转 | M2 + 编码器 |
| M5 | **堵转辅助判定** | 编码器=0 但陀螺检测到周期性微振动（电机通电抖动）→ 佐证堵转，缩短 bit5 判定时间、减少误判 | M2 |
| M6 | **振动/共振监测** | 加速度 RMS/峰值；超阈值告警（搅拌不平衡、桨叶碰壁） | G2 |
| M7 | **安装倾斜/倾倒保护** | roll/pitch 超阈值 → 禁止启动（选配） | G9 |

> **推荐组合：M1 + M2 + M3（基础）+ M4 + M5（价值最高）。** M6/M7 作为可选开关。
> **不建议**做"角加速度闭环"：搅拌负载惯量与液体阻尼强耦合，α 闭环极易振荡，收益低风险高（列为 P3 可选）。

### 3.1 任务与周期

| 任务 | 周期 | 职责 | 优先级 |
|---|---|---|---|
| 新增 `IMU` 任务 | **10 ms（100 Hz）** | 读 6 轴 → 滤波 → 零偏扣除 → 姿态/判据 → 快照 | PRIO_3（同 UI） |
| 现有 `CTRL` 任务 | 200 ms | 用 IMU 快照做：加减速斜坡、打滑/堵转辅助判定（**只读快照，不阻塞 SPI**） | PRIO_5（不变） |
| 中断 | INT1 数据就绪 | 仅 `vTaskNotifyGiveFromISR` 唤醒 IMU 任务（ISR 只通知） | — |

- SPI 单次读 12 B（6 轴）+ 1 B 温度，9 MHz 下 < 20 µs，100 Hz 占用忽略不计；
- 优先级 3 与 UI 相同，避免抢占控制环；
- 心跳：IMU 任务加入 `app_fault` 心跳源（`APP_HB_IMU`），卡死也能被 WDG 抓到（**需扩展心跳枚举，属改动点**）。

### 3.2 与已验收功能的隔离原则

1. **IMU 全程"只读旁路"**：即使 IMU 不存在/数据无效，电机、加热、UI、通信全部照旧（`imu_valid=0` 时所有判据自动降级为"不参与"）；
2. 不修改 `app_motor` 的 PID 结构，只在**设定值生成**处插入斜坡（M1），可用宏/运行开关关闭（关闭后行为与 v1.1 完全一致）；
3. 不改 `app_heat` / `app_temp` / `app_store` 的既有字段语义，EEPROM 扩展走独立区块（见 §5.2）。

## 4. 算法方案

### 4.1 采集与预处理

1. `ODR = 208 Hz`（6 轴），`LPF2` 使能（≈ODR/4），高速时切 416 Hz；
2. 原始值 → `mg`（加速度）、`mdps`（角速度）：
   - `acc_mg = raw * (FS_g * 1000 / 32768)`
   - `gyro_mdps = raw * (FS_dps * 1000 / 32768)`
3. 零偏：上电静止 1~2 s 取均值（仅角速度），或面板/通信触发"零偏标定"；
4. 温度补偿（可选）：`bias(T) = bias25 + k*(T - 25)`，k 由 2 点标定得到；
5. 输出：`acc[3] (mg)`、`gyro_bias_free[3] (0.1 dps)`、温度 `(0.1℃)`。

### 4.2 姿态解算（P1）

- `roll = atan2(ay, az)`、`pitch = atan2(-ax, sqrt(ay²+az²))`（加速度，静态准确、动态受线加速度干扰）；
- 陀螺积分 + 互补滤波（`α=0.98`）或 Mahony，输出 `roll/pitch/yaw` 与四元数；
- **yaw 会漂移**（无磁力计），文档与上位机需标注"相对角度、仅用于趋势/事件"；
- 本应用只需 roll/pitch 做倾斜判定，yaw 仅做"转动累计圈数"参考。

### 4.3 电机加减速（核心）

#### M1 速度斜坡（S 曲线）

```
目标转速 n_tgt（RPM）
    │        ┌─────────────  匀速
    │      ╱
    │    ╱  加速段：a ≤ a_max（RPM/s 或 dps/s）
    └──╱──────────────► t
```

- 参数：`a_max`（默认 600 RPM/s）、`j_max`（S 形加加速度限制，可选）；
- 200 ms 周期内：`n_cmd += clamp(a_max * 0.2s, ±(n_tgt - n_cmd))`；
- 停机同理（减速）；定时到、故障、堵转一律走**减速停机**（不再直接 0%）；
- 关掉时（开关=0）行为与 v1.1 完全一致。

#### M2 实测角加速度

```
α = (ω[k] - ω[k-1]) / Δt        Δt = 10 ms
α_f = α 经一阶低通（τ ≈ 50 ms）
```
输出：`0.1 dps/s` 定点（int16，±3276 dps/s 足够）。

#### M3 加减速事件

| 事件 | 判据 | 用途 |
|---|---|---|
| 加速开始 | `α_f > +α_th` 连续 3 拍 | 记录起点时刻 |
| 加速结束 | `|α_f| < α_th` 且 `ω > 0.9·ω_tgt` | 算加速时间/超调 |
| 减速开始/结束 | 同上取负 | 算减速时间、停止冲击 |
| 冲击 | `|α| > α_impact`（默认 2000 dps/s） | 记录峰值（防止液体涌浪/机械冲击） |

#### M4 打滑/失步（陀螺 × 编码器交叉校验）

前提：陀螺与电机**同轴/刚性同转**（安装要求见 §6）。

```
ω_enc（编码器，RPM） 与 ω_imu（陀螺，dps→RPM 换算）
err = |ω_imu - k·ω_enc| / max(ω_enc, 50RPM)
err > slip_th（默认 15%）持续 1 s  →  打滑标志（状态位，不直接停机）
```
价值：联轴器松动、皮带打滑、桨叶脱落（空转）都能被抓到；这是**陀螺最实在的贡献**。

#### M5 堵转辅助（与现有 bit5 联动）

现有堵转判据（v1.1）：目标>0 + 占空比≥40% + RPM<目标×25% + 连续 3 s。
新增辅助：编码器 RPM≈0 但 `vib_rms > vib_th`（陀螺/加速度检测到电机通电抖动）→ **判定时间由 3 s 缩短到 1 s**，并可区分"机械抱死"（无振动）与"电气堵转"（高频抖动）。

> 该改动默认**关闭**，需实机验证后才打开（避免误停机）。

### 5.2 参数存储（EEPROM）

> 现状：v5 主结构**正好 96 字节 = 一个槽**，已无空间。

**方案：独立扩展块，占用 v1 遗留空闲区 `0x00~0x3F`（64 B），不动主槽。**

| 地址 | 内容 |
|---|---|
| 0x00~0x1F | IMU 参数块 A（magic `0x494D`('IM') + version + CRC16） |
| 0x20~0x3F | 同块备份 B |

块内字段（约 40 B）：

| 字段 | 类型 | 默认 |
|---|---|---|
| enable | u8 | 1 |
| accFs / gyroFs / odrCode / lpfCode | u8×4 | 0(±2g) / 0(±125dps) / 3(208Hz) / 1 |
| biasX/Y/Z | int16×3（0.01 dps） | 0 |
| tempCoefX/Y/Z | int16×3（0.01 dps/℃） | 0 |
| alphaLimit | u16（dps/s） | 600 |
| slipTh / vibTh / tiltTh | u16×3 | 150(15%) / 300mg / 450(45°) |
| rampAccRpmS / rampDecRpmS | u16×2 | 600 / 600 |
| slipAssistStallEn | u8 | 0（默认关） |

> 说明：v1 区在 v2 迁移完成后一直是只读保留、从未被使用，用作扩展块**不会破坏主参数**，且与主槽物理隔离，符合"不影响已验收功能"。

## 6. 安装与标定要求（必须满足，否则 M4/M5 无效）

1. **刚性同轴**：传感器 PCB 必须与电机轴（或搅拌轴）刚性连接，否则陀螺测的是"板子自己的角速度"，M4 打滑判据不成立；
2. 若传感器固定在机壳（不随轴转），则陀螺只能测"机壳反扭矩引起的微小转动/振动"，**只能做振动/倾斜/启动冲击**，不能做打滑判定 —— 需在方案确认时明确安装方式；
3. 轴向对齐：软件提供 `axisMap`（X/Y/Z 取反/交换），标定时"正向旋转时 ω_Z 为正"；
4. 零偏标定必须**静止无扰**（每次上电自动做 1~2 s，或手动触发）；
5. 温度变化 > 10℃ 建议重新标定（或启用温补系数）。

## 8. 风险与已知限制

| 风险 | 影响 | 对策 |
|---|---|---|
| 板上未贴 LSM6DSM | 全部功能无效 | 先确认 BOM/实物；未贴件则本方案搁置 |
| 安装未同轴 | M4 打滑判据失效 | 明确安装方式（§6），否则删除 M4 只做振动/倾斜 |
| 陀螺零偏漂移 | yaw 长时漂移 | 只用 roll/pitch；yaw 标"相对"；静止时零速修正（ZUPT） |
| 积分/微分噪声 | α 抖动误判 | 一阶低通 + 阈值 + 连续 3 拍确认 |
| 寄存器表扩展 | 旧 App 只读前 32 个 | 兼容（旧 App 不受影响，新功能需更新 App） |
| EEPROM 新块 | 与主槽并发写 | 复用同一防抖落盘机制，2 s 静置后统一写 |
| 增加 IMU 任务 | CPU/优先级 | 100 Hz、单次 <100 µs；PRIO_3，不抢控制环 |

## 9. 需要你确认的 7 件事（确认后我再动手写代码）

1. **硬件**：板上 LSM6DSM 是否已贴件？（能否先读 `WHO_AM_I` 验证）
2. **安装方式**：传感器**随轴转动**（可做打滑判定 M4）还是**固定在机壳**（只能做振动/倾斜/冲击）？
3. **加减速目标**：只要"设定值斜坡 + 实测验证"（M1+M2+M3），还是要"角加速度闭环"（不建议）？
4. **打滑/堵转辅助**是否要？（M4/M5，M5 默认关）
5. **寄存器表扩到 64 个**（0x0020~0x003F）是否可接受（App/网页需同步）？
6. **EEPROM 扩展块**用 v1 空闲区（0x00~0x3F）是否可接受？
7. **OLED** 是否新增"IMU 页"（长按/短按某个键切换，显示 6 轴/姿态）？还是只在串口与 App 上显示？
