# TempStir 智能温控搅拌机 · 使用文档

> 适用固件：**v1.1**（Modbus 寄存器 `0x000F` = `0x0101`）
> 目标板：STM32F103RCT6 / STM32Cube HAL / FreeRTOS
> 工程：`MDK-ARM/TempStirV1.0.uvprojx`（Keil MDK V5.38 / ARMCC V5）
> 本文覆盖：**安装接线 → 上电 → 面板操作 → 控温/搅拌规则 → 通信 → 保护与故障码 → 烧录调试 → 出厂自检 → 老化测试 → 已知限制**

---

## 1. 产品概述

智能温控搅拌机：铝板加热 + 搅拌电机，双路 NTC 测温（液体 / 铝板），OLED 面板设定，支持 RS485/Modbus 与 BLE 蓝牙两路上位机，参数掉电保存，RTC 走时。

### 1.1 功能清单

| 功能 | 说明 | 状态 |
|---|---|---|
| 双路测温 | 液体 NTC（PB1）+ 铝板 NTC（PB0），Steinhart-Hart 换算 + 8 点滑动平均 + 断线/短路判定 | ✅ |
| 加热控温 | 液体目标温度 PID 闭环，PWM 20 kHz（TIM2_CH1 / PA0） | ✅ |
| 铝板限温 | 板温 ≥ 上限锁存断电，降到「上限 − 2.0℃」解除；`0` = 不限制 | ✅ |
| 搅拌调速 | 编码器测速 + 转速 PID 闭环，PWM 20 kHz（TIM4_CH3 / PB8） | ✅ |
| 堵转保护 | 占空比大但转速起不来，持续 3 s → 停机 + 故障位 bit5 | ✅ |
| 风扇自动 | 板温 ≥35℃ 开 / ≤32℃ 关，最短切换间隔 5 s | ✅ |
| 蜂鸣提示 | 短鸣 / 长鸣（4 kHz 无源，TIM1_CH1 / PA8） | ✅ |
| 面板 UI | 0.96" OLED 128×64 + 4 按键，6 行「设定/实测」 | ✅ |
| 定时 | 0~999 s，电机启动开始倒计时，归零自动停机 | ✅ |
| 参数存储 | M24C02 EEPROM，双槽 + CRC16 + 版本迁移（v4） | ✅ |
| RTC | DS3231 走时 + 1 Hz SQW 秒节拍，面板/串口校时 | ✅ |
| RS485 / Modbus RTU | UART4，9600 8N1，从机 1，32 个保持寄存器（03/06/10） | ✅ |
| BLE 蓝牙 | USART2 + ECB01C 透传，同一套 Modbus 帧 | ✅ |
| 故障监控 / 看门狗 | 故障字聚合、三源心跳、IWDG ≈1.6 s、上电打印复位原因 | ✅ |
| CAN | 本期未实现 | ⛔ |

## 2. 硬件接口

### 2.1 引脚与信号

| 功能 | 网络 | 引脚 | 说明 |
|---|---|---|---|
| 铝板 NTC | BOARD_ADC | PB0 / ADC1_IN8 | 10k 分压，室温 25℃ 原始值约 **2047** |
| 液体 NTC | LIQUID_ADC | PB1 / ADC1_IN9 | 同上 |
| 加热电流 | HEAT_I_ADC | PA4 / ADC1_IN4 | INA199 放大，R29 5 mΩ 采样 |
| 24 V 电压 | SUPPLY_24V_ADC | PC0 / ADC1_IN10 | 电源电压检测 |
| 加热 PWM | HEAT_PWM | PA0 / TIM2_CH1 | **20 kHz**，占空比 0~100% |
| 风扇 | MOTOR_ON | PA1 | **高有效** |
| 电机 PWM | MOTOR1 | PB8 / TIM4_CH3 | **20 kHz**；PB9（MOTOR2）**必须固定低**（拉高会反转/刹车） |
| 编码器 | M1_ENC_A/B | PB4 / PB5 / TIM3 | 正交编码器接口 |
| 蜂鸣器 | BUZZ | PA8 / TIM1_CH1 | 4 kHz 无源，50% 占空比驱动 |
| 按键 | KEY1~KEY4 | PC6 / PC7 / PC8 / PC9 | 内部上拉，按下接地（低有效） |
| OLED | — | PB6 / PB7（I2C1） | SSD1315，地址 0x3C 类 |
| EEPROM | — | PB10 / PB11（I2C2） | M24C02 |
| RTC | — | PB10 / PB11（I2C2） | DS3231；SQW → PC12（DS_INT） |
| 加热故障锁存 | HEAT_FAULT_N | PC3 | **低有效**（74LVC1G74 锁存），复位脚 FAULT_RST_N = PC2 |
| 调试串口 | — | PA9 / PA10（USART1） | **115200 8N1**，printf 重定向 |
| RS485 | — | PC10 / PC11（UART4） | MAX13487E 自动方向 |
| 蓝牙 | — | PA2 / PA3（USART2） | ECB01C，9600 8N1 |
| 调试口 | SWD | PA13 / PA14 | CMSIS-DAP |

### 2.2 上电顺序建议

1. 接好 24 V 加热电源与 MCU 电源（**加热组件禁止空载长时间通电**）；
2. 接好调试器（CMSIS-DAP）或 USB-串口（看日志）；
3. 上电 → OLED 显示 `TempStir V1.0`，串口打印启动信息（见 3.2）。

## 3. 上电与日志

### 3.1 上电默认状态

| 项 | 上电值 |
|---|---|
| 电机 | **停止**（必须人为启动） |
| 加热 | 关闭（需设定液体目标 + 启动电机） |
| 速度 / 液体目标 / 定时 | 从 EEPROM 恢复（默认 0 / 0 / 0） |
| 铝板上限 | 从 EEPROM 恢复（默认 **40℃**；旧固件的 1~34℃ 非法值会自愈为 40℃） |
| 通信 | RS485 + 蓝牙都开，9600 8N1，从机地址 1 |
| 蜂鸣器 | 静音 |

### 3.2 启动日志（USART1，115200）

```
[P7] reset cause: IWDG=0 WWDG=0 SW=0 POR=1 PIN=1 LPWR=0
[P7] fault monitor init
[P5] EEPROM=OK
[P5] DS3231=OK 2026-11-05 11:23:41 valid=1 sqw=1
[P5] PARAM speed=0 plate=40 liquid=0 time=0
[P5] CALIB mPID=2000/500/0 hPID=2000/50/0 PPR=44 gearX100=3000
[P5] STAT boot=85 run=2350 s heat=5211 s start=37
[P6] BLE baud=9600 (AT ok)
[P6] BLE name=BT_ECB1A6B01BA2 link=disconnected baud=9600
[P7] IWDG on (timeout ~1600 ms)
```

关键判读：

- `reset cause: IWDG=1` → 上次是**看门狗复位**（任务卡死/异常），不是正常上电；
- `EEPROM=NG` → 参数无法保存（检查 I2C2 / 芯片）；`DS3231=NG` → 时间不可用；
- `RTC time lost (OSF=1)` → 纽扣电池没电/未装，已用编译时刻兜底；
- `BLE ... link=disconnected` → 蓝牙在线但未连接手机，属正常。

## 4. 面板操作

### 4.1 按键

| 按键 | 短按 | 长按（≥600 ms） |
|---|---|---|
| **KEY1**（PC6） | 切换焦点：速度 → 铝板 → 液体 → 时间 → 循环 | 进入/退出 **RTC 校时页** |
| **KEY2**（PC7） | 当前项 **+1 步** | 600 ms 后每 80 ms 连发 |
| **KEY3**（PC8） | 当前项 **−1 步** | 600 ms 后每 80 ms **连发减值**（原「长按进六轴页」已停用，见 5.6） |
| **KEY4**（PC9） | **启动 / 停止电机**（启动即开始倒计时） | 进入 / 退出 **标定页**（见 4.5） |

> 焦点行前有 `>` 箭头。面板任意按键后 **8 s 内**通信写命令会被拒绝（返回异常码 06，防抢控）。
>
> **KEY4 为"松手生效"**：按下不动作，松开瞬间才执行启动/暂停（校时页=写入并退出、标定页=保存并退出）。长按 ≥600 ms 只切换页面，**不会改变电机启停状态**。KEY1/KEY2/KEY3 仍是"按下即触发"。

### 4.2 主界面（6 行，"设定/实测"）

```
TempStir V1.0
>Speed  100/80 rpm      设定转速 / 编码器实测转速（电机轴 RPM）
 Plate   60/25 C        铝板上限温度 / 铝板实测温度
 Liquid  45/23 C        液体目标温度 / 液体实测温度
 Time   60/45 s         设定时间 / 剩余时间（秒）
 Motor  Running         运行状态：Running / Idle
```

- 实测温度显示 `--` 表示 NTC 采样失败（断线/短路）；
- 无按键时每 480 ms 刷新一次；RTC 1 Hz 秒节拍到来时立即刷新。

### 4.3 参数范围

| 项 | 范围 | 步长 | 说明 |
|---|---|---|---|
| Speed | 0 ~ 500 rpm | 5 | 电机轴 RPM，与编码器同量纲 |
| Plate | 0 ~ 120 ℃ | 1 | **上限（保护门限）**；`0`=不限制；有效域 `{0} ∪ [35,120]`，1~34 会被当作 0 |
| Liquid | 0 ~ 100 ℃ | 1 | **加热目标**；`0` = 不加热 |
| Time | 0 ~ 999 s | 1 | `0` = 不限时 |

### 4.4 RTC 校时（长按 KEY1）

```
Set RTC
Date 2026-11-05
Time 11:23:41
K1  next field
K2+ K3-  K4 save
Motor  Idle
```

- KEY1 循环切换 **年 / 月 / 日 / 时 / 分 / 秒**；
- KEY2/KEY3 增减（年 2000~2099、月 1~12、日按当月天数、时分秒 24/60 循环）；
- KEY4 **松开时**写入 RTC 并退出；星期自动推算。

### 4.5 标定页（长按 KEY4 进入，KEY4 保存并退出）

出厂/维修标定用，**只改标定参数，不动速度与温度目标，也不改变电机/加热状态**。

```
CALIB 3/8
NTC R25 ohm
10000 ohm
K1 next  K2+ K3-
K4 save+exit
Motor  Idle
```

| 序号 | 项目 | 含义 | 范围 / 步长 |
|---|---|---|---|
| 1 | Encoder PPR | 编码器每转计数（线数×4） | 4~4096，步 4 |
| 2 | Gear x100 | 减速比×100（例 `3000` = 30.00） | 100~10000，步 100 |
| 3 | NTC R25 ohm | NTC 25℃ 阻值 | 1000~100000Ω，步 500 |
| 4 | NTC B (K) | NTC B 常量 | 1000~6000K，步 50 |
| 5 | NTC Rup ohm | 分压上拉电阻 | 500~100000Ω，步 500 |
| 6 | Heat OC raw | 加热过流判定阈值（ADC 原始值） | 500~4000，步 50 |
| 7 | Liquid off | 液体温度校准偏移 | −100~100（0.1℃），步 1 |
| 8 | Board off | 铝板温度校准偏移 | −100~100（0.1℃），步 1 |

- KEY1 切换项目（循环），KEY2/KEY3 增减（长按连发），**KEY4 短按松开即保存并退出**（写 EEPROM + 立即生效，无需重启）；
- 长按 KEY4（≥600 ms）只进出标定页，**不保存**；按住期间不会误改电机启停；
- 标定时建议电机停止，改完 NTC 参数后观察主界面实测温度与实际温度是否一致，再用偏移微调；
- 保存时串口打印 `[P8] CALIB saved: ppr=… gearX100=… R25=… B=… Rup=… OC=… offL=… offB=…`。

## 5. 控制逻辑与安全行为

### 5.1 温度语义（**重要**）

| 项 | 含义 |
|---|---|
| 面板 **Liquid** | **加热目标温度**（唯一 PID 设定值）。=0 时不加热。 |
| 面板 **Plate** | **铝板上限温度 + 铝板实测值**。上限只做保护，**不是加热目标**。 |

> 想加热：设 `Liquid`（如 30~45℃），并**启动电机**；`Plate` 保持 40℃ 作为板温上限即可。

### 5.2 加热启动条件（全部满足才加热）

1. 无加热类故障（HEAT_FAULT_N / 过流 / NTC 异常 / 铝板限温锁存）；
2. **电机运行中**（目标转速 ≠ 0 且未堵转）；
3. 液体目标温度 > 0；
4. 液体温度低于目标（或 PID 输出 > 0）。

### 5.3 加热停止条件

| 触发 | 行为 | 恢复 |
|---|---|---|
| 液体到目标（曾低于目标后首次达到） | 关加热**锁存** + 蜂鸣长鸣 1 s + 状态字 bit9 | 改液体目标 / 重新启停电机 / `0x0007` 清故障 |
| 铝板 ≥ 上限 | 关加热锁存 + 故障位 bit4 | 板温降到「上限 − 2℃」以下，或改上限，或清故障 |
| 板温 NTC 无效 | 立即关加热（fail-safe）+ 故障位 bit3 | NTC 恢复正常见后自动恢复 |
| 电机停机 / 堵转 | 撤销加热许可 | 重新启动电机 |
| 加热硬件故障 / 过流 | 立即关加热 + 故障位 bit0/bit1 | 排除硬件后清故障（`0x0007` bit2） |

### 5.4 其它自动行为

- **风扇**：板温 ≥35.0℃ 开、≤32.0℃ 关，两次切换至少间隔 5 s；
- **液温上穿 30.0℃**：蜂鸣长鸣 1 s（边沿触发，**下降不响**；默认不停电机，宏 `APP_TEMP_MARK_STOP_MOTOR` 可改为同时停机）；
- **定时**：KEY4 启动即开始倒计时，归零自动停机并落盘统计；
- **统计**：累计运行时间 / 加热时间 / 启动次数，每 5 分钟或停机时写 EEPROM。

### 5.5 保护一览

| 保护 | 阈值 / 判据 | 动作 |
|---|---|---|
| 加热硬件故障 | HEAT_FAULT_N 低 | 关加热，故障位 bit0 |
| 加热过流 | 电流 ADC raw > 3500（**待整定**） | 关加热，故障位 bit1 |
| 液体 / 铝板 NTC 断线短路 | raw < 100 或 > 4000 | 关加热（液体 NTC 异常也禁止加热） |
| 铝板限温 | 板温 ≥ 上限（回差 2.0℃） | 关加热锁存，故障位 bit4 |
| 电机堵转 | 目标>0 且占空比≥40% 且 RPM<目标×25% 且 <10，连续 3 s | 停机锁存，故障位 bit5 |
| 任务卡死 | 任一关键任务心跳丢失 >500 ms | WDG 停喂，IWDG 约 1.6 s 复位 |
| EEPROM / RTC 异常 | 探测失败 / OSF=1 | 故障位 bit6 / bit7（不禁止加热/电机） |
| 倾斜保护（P9） | max(\|roll\|,\|pitch\|) > 门限（默认 10.0°，0x0036）持续 500 ms，回差 3.0° 且持续 500 ms 解除 | 电机运转中立即停机 + 蜂鸣器长鸣；状态位 0x002A bit8 = 倾斜锁存 |
| 打滑告警（P9/M4） | 陀螺推算转速与编码器偏差 > 门限（默认 15.0%，0x0034）持续 1 s | **当前默认关闭**（IMU 固定底座，见 5.6）；仅在 `APP_IMU_SLIP_ENABLE=1` 时生效：仅告警不停机 |
| 升温异常（A3） | 目标液温>0、占空比 ≥50%、电机运行中，120 s 内液温上升 <2.0℃ | **仅告警**：状态字 bit12 + 蜂鸣 1.5 s + 串口 `[P11] liquid no-rise`（不停机、不关加热） |
| 板温不升（P10，默认关） | 板温目标模式下占空比 ≥50% 且板温 raw 30 s 不动 | 关加热锁存（该模式默认关闭） |
| 堵转辅助（M5，默认关） | 0x003B bit0=1 且 IMU 检测到振动（振动 RMS > 0x0035） | 堵转判定时间 3 s → 1 s |

### 5.6 六轴（LSM6DSM）相关行为

- 采集：SPI2 100 Hz（CS=PB12），上电 2 s 自动零偏标定并落盘；未贴件/通信失败时所有判据自动降级，**电机/加热/通信不受影响**（故障位 bit8 提示）；
- 倾斜保护：见 5.5。倾角超限会**停机**，因此“倾斜锁存期间 App/面板再按启动会被再次停掉”属预期行为；
- 打滑（M4）：**默认关闭**。本机 IMU 固定在底座、不随搅拌轴转动，陀螺测不到转速（ω_imu 恒 0），偏差恒为 100.0%，会误报 bit7/状态字 bit11，故 `APP_IMU_SLIP_ENABLE=0`；判据代码保留，将来若 IMU 改为随轴装配再置 1。关闭后 `0x002F` 恒 0；
- 参数（打滑/振动/倾斜/斜率/过流）可现场改：面板标定页覆盖 PPR/减速比/NTC/过流/温度偏移，**六轴门限用 App「六轴门限 / 参数设置」或网页版参数区**（写 0x0033~0x0036、0x003A），即时生效并掉电保存；
- **面板六轴显示页（原第 7 页，长按 KEY3 进出）已停用**：该页占用 KEY3 长按，导致长按无法连发减值，故 `menu_ui.c` 的 `MENU_UI_IMU_PAGE_ENABLE=0`，入口不调用、KEY3 长按归还连发；页面代码完整保留，改宏为 `1` 重烧即恢复（届时 KEY3 长按会被页面占用）。六轴数据仍可通过 0x0020~0x0032 读取（App/网页版）；
- 可选扩展（默认全关，需改宏重烧并实机复验）：`APP_IMU_SELFTEST_ENABLE`（上电 CTRL5_C 自检）、`APP_IMU_FIFO_ENABLE`（FIFO 批量采样）、`APP_MOTOR_STALL_ASSIST_DEFAULT`（运行期默认开辅助堵转）。

## 6. 通信

### 6.1 RS485 / Modbus RTU（**当前版本不支持**）

> ⚠️ **本版本不使用 RS485 通道**：主站实测所需的 USB-485 转换器未到位，且该通道不在本版出厂功能范围内。
> 代码保留（UART4 + MAX13487E），但**不要按 RS485 交付**；下表的寄存器/帧格式仍然有效，**通过蓝牙访问**。

- 参数（蓝牙链路）：**9600 8N1，从机地址 1**；
- 功能码：`03` 读保持寄存器、`06` 写单个、`10` 写多个；
- 异常码：`02` 非法地址、`04` 数值非法/保护联锁、`06` 从机忙（面板 8 s 占用）。

### 6.2 保持寄存器表（**64 个，0x0000~0x003F**；v1.2 起扩表，旧上位机只读前 32 个不受影响）

| 地址 | 名称 | 类型/单位 | 读写 | 说明 |
|---|---|---|---|---|
| 0x0000 | 当前液温 | int16 / 0.1℃ | R | |
| 0x0001 | 目标液温 | int16 / 0.1℃ | R/W | 0~1000（0~100.0℃），即加热目标 |
| 0x0002 | 当前转速 | int16 / rpm | R | 编码器实测（电机轴） |
| 0x0003 | 目标转速 | int16 / rpm | R/W | 0~500 |
| 0x0004 | 剩余时间 | uint16 / s | R | |
| 0x0005 | 系统状态字 | 位域 | R | 见 6.4 |
| 0x0006 | 故障码 | 位域 | R | 见 6.5 |
| 0x0007 | 控制命令 | 位域 | R/W | 见 6.6（写入后自动执行） |
| 0x0008 | 铝板温度 | int16 / 0.1℃ | R | 实测 |
| 0x0009 | 加热占空比 | uint16 / % | R | |
| 0x000A | 电机占空比 | uint16 / % | R | |

### 6.7 BLE 蓝牙

- 模块：ECB01CV2-SOP8，出厂名 **`BT_ECB1A6B01BA2`**（名字由 MAC 派生，**不支持自定义名**）；
- 连接方式：**必须用 BLE 工具（如 nRF Connect）连 GATT**，手机系统"配对"会提示失败，属正常；
- 服务 / 特征：`FFF0`（服务）、`FFF1`（Notify，**需在手机侧手动订阅**）、`FFF2`（Write）；
- MTU 未协商（=23）时单包 ≤20 字节，**一次读 ≤7 个寄存器**；MTU 247 可整表读；
- 帧格式与 RS485 完全相同（Modbus RTU + CRC16，主站侧需自行组帧）。

### 6.8 上位机

| 上位机 | 位置 / 方式 |
|---|---|
| 安卓 App「TempStir 蓝牙控制台」 | BLE GATT 直连，功能等同面板 |
| 网页版 | `Doc/web/tempstir_rs485.html`，Chrome/Edge 的 **Web Serial** → USB-485 → 板载 485A/485B。1 s 轮询 0x0000~0x0015，**并追加读 0x0020~0x003F**（六轴/参数区，旧固件自动停读），参数区可写入打滑/振动/倾斜/斜率/过流并开关「辅助堵转 / 统计打印」。**⛔ 本版不支持 RS485，此上位机暂不可用**（文件保留备查） |

> 注意：CherryUSB CMSIS-DAP 的虚拟串口（COM5）**不是** 485 通道，网页版必须选 USB-485 转换器的串口。

## 7. 参数存储与 RTC

- **EEPROM（M24C02，v5）**：UI 参数、PID 增益（×1000）、校准系数（PPR/减速比/温度偏移）、**NTC 曲线参数（R25/B/上拉）与加热过流阈值**、通信参数、运行统计；双槽 + CRC16 + 版本迁移（v4 及更早数据上电自动迁移，新字段补默认值）；
- 写入策略：参数改动**静置 2 s** 落盘（防按键连发磨损），统计每 5 分钟或停机落盘；
- **v4 → v5 迁移已实测通过**：升级后启动日志出现 `[P8] NTC R25=10000 B=3950 Rup=10000 | heatOC=3500 | offL=0 offB=0`，且 `[P5] STAT boot=` 连续递增（85 → 90），说明旧参数与统计被沿用、未退回默认值；
- **RTC（DS3231）**：OSF=1 时用编译时刻兜底并打印提示；1 Hz SQW 经 PC12 通知 UI 刷新。

## 12. 常见问题（FAQ）

**Q1：启动电机后不加热？**
A：① `Liquid` 是否为 0（0 = 不加热）；② 故障字是否为 0（bit2/3/4 会禁止加热）；③ 板温是否已达 `Plate` 上限。

**Q2：加热到目标就停了，之后不再加热？**
A：这是"到温完成"锁存（正常）。改一下 `Liquid` 目标、重新启停电机，或写 `0x0007` 清故障即可重新加热。

**Q3：OLED 上温度显示 `--`？**
A：该路 NTC 采样失败（断线/短路）。故障位 bit2/bit3 会置位，加热会被禁止。

**Q4：手机蓝牙"配对失败"？**
A：该模块是 BLE 透传，不走经典配对。请用 nRF Connect 等工具连 GATT（FFF0/FFF1/FFF2），并手动订阅 FFF1。

**Q5：蓝牙读回来是乱码/无响应？**
A：① 是否订阅了 FFF1；② MTU 23 时一次读 ≤7 个寄存器；③ 帧必须带 CRC16。

**Q6：面板改了参数，App 写不进去？**
A：面板操作后 8 s 内通信写会被拒绝（异常码 06），属仲裁设计。

**Q7：板子上电后约 12 s 自动重启？**
A：仅存在于已删除的 IWDG 自检版本（`APP_IWDG_TEST_ONESHOT=1`）。当前固件无此行为；若仍出现，检查 `reset cause` 是否为 `IWDG=1`（真故障）或 `POR=1`（电源不稳）。

**Q8：烧录报 `Target DLL has been cancelled`？**
A：探针会话未建立，通常重试一次即可；仍失败检查 CMSIS-DAP 连接与目标供电。

**Q9：实测温度与实际差几度，怎么校准？**
A：长按 KEY4 进标定页 → 先按 NTC 实际规格改 `R25`/`B`/`Rup`（第 3~5 项）→ 保存；若仍有固定偏差，再用第 7/8 项温度偏移微调（单位 0.1℃）。改完即时生效。

**Q10：转速显示不准？**
A：标定页第 1 项 `Encoder PPR`（线数×4）与第 2 项 `Gear x100`（减速比×100）。可先设一个已知转速，按"显示值/实际值"比例修正 PPR。

**Q11：能用 RS485 接电脑吗？**
A：**本版不支持**。请用手机 BLE（`BT_ECB1A6B01BA2`，FFF0/FFF1/FFF2）。
